# Hswele Ehin Tse Portfolio 3

A Next.js portfolio for UI/UX and product designer Hswele Ehin Tse. The design follows a fairground carousel concept with a project picker, case study tickets, process, experience, skills, and contact sections.

## Run locally

```bash
npm run dev
```

## Build a static export

```bash
npm run build
```

The static site is written to `out/`.
